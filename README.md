## 🚀 Projets majeurs

### 🧏‍♂️ Traduction de la Langue des Signes en Temps Réel
> Système de traduction de la langue des signes vers du texte (et inversement via avatar 3D)

- MediaPipe pour l’extraction des landmarks (mains + visage)
- Pipeline temps réel basé sur OpenCV
- Modèle de reconnaissance des glosses par LSTM
- Traduction des glosses → anglais naturel avec BERT
- Backend : **FastAPI**
- Frontend : **JavaScript**
- Communication temps réel : **WebRTC**
- Animation de l’avatar 3D : **Unity**
- Objectif : accessibilité, inclusion et performance temps réel

---

### 💬 Application de messagerie
- Envoi de messages textuels
- Partage de fichiers
- Communication peer-to-peer avec **WebRTC / PeerJS**
